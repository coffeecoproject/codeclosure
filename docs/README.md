## Document Status Vocabulary

- **Canonical** — defines the current product contract.
- **Accepted ADR** — a current architectural decision.
- **Planned** — intended work that is not implemented yet.
- **Review** — an assessment of canonical sources at a point in time; not a new
  authority.
- **Reference** — external or historical material that informs design but does
  not define behavior.
